---
title: "Node Active FS"
description: "Use one familiar file system interface across local files, memory, Amazon S3, and Enstore."
---

`nafs` selects a storage backend from a URI and returns a Node-style file system interface. Application code can use familiar methods such as `promises.readFile`, `promises.writeFile`, `createReadStream`, and `createWriteStream` without constructing each backend directly.

```bash
npm install nafs
```

```ts
import { nafs } from 'nafs'

const fs = await nafs(':memory:')

await fs.promises.writeFile('/hello.txt', 'Hello from nafs')
console.log(await fs.promises.readFile('/hello.txt', 'utf8'))
```

## URI at a glance

| Backend | URI |
| --- | --- |
| Local directory | `file:///absolute/path` or `file://relative/path` |
| Memory | `:memory:` |
| Amazon S3 | `s3://bucket/optional/prefix` |
| Enstore | `enstore://username:password/optional/prefix?endpoint=https%3A%2F%2Fexample.com%2Fenstore` |

<Note>
  Backend packages are optional peer dependencies. Install only the packages needed by your chosen backend.
</Note>
